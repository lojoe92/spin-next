Sync with your sheet

Ratings are written to the Rating and Review Date columns of the Ratings Chart tab through a small Google Apps Script you deploy once.

Set-up, once

  1. Open 1001 Albums.xlsx in Google Sheets and choose File › Save as Google Sheets.
  2. In the new sheet, open Extensions › Apps Script, paste apps-script/Code.gs from the project and change TOKEN.
  3. Run setup2026 once. It adds the 13 new albums and the 2026 Edition column.
  4. Deploy › New deployment › Web app, execute as Me, access Anyone. Paste the URL above.
